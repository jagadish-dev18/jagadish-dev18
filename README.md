### 🛡️ 3. LinkLens — URL Security Checker

A browser-based tool that inspects URL structures and explains suspicious characteristics that may require further investigation.

- Analyze a single URL or multiple URLs.
- Accept TXT or CSV input where supported.
- Parse protocol, hostname, port, path, and other URL components.
- Check indicators such as IP-based hostnames, embedded credentials, unusual characters, punycode, long URLs, unusual ports, and suspicious patterns.
- Display individual findings and an explainable heuristic score.
- Maintain recent scan history in browser storage.
- Export analysis results as CSV or JSON.

**Tech Stack:** HTML5, CSS3, JavaScript, URL API, `localStorage`, CSV/JSON

**Important Limitation:** The basic browser-only version performs URL-structure analysis. It does not independently verify every URL against live threat-intelligence databases. A low score does not prove that a URL is safe.

**Key Concepts:** URL parsing, validation, conditional logic, safe rendering of user input, scoring rules, and report generation.

### 🔎 4. Log Sentinel — Failed Login Attempt Log Analyzer

A security log-analysis tool that summarizes authentication events and flags repeated failed-login attempts for further review.

- Read sample authentication logs and identify supported successful and failed login events.
- Count failed login attempts by source IP address.
- Compare failed-attempt counts against a configurable threshold.
- Display recognized events, unparsed lines, and IP addresses flagged for review.
- Generate an IP-wise summary and export the results as CSV.
- Includes a browser-based interface and a Python command-line analyzer.

**Tech Stack:** Python, HTML5, CSS3, JavaScript, file handling, dictionaries, CSV

**Key Concepts:** Log parsing, string processing, dictionaries, event grouping, threshold checks, input validation, and report generation.

**Important Limitation:** The analyzer processes selected log files. It does not monitor a live network or prove that a flagged IP address belongs to an attacker.
