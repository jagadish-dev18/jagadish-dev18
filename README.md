🔗 **Live Demo:** [Open MaintainIQ](https://jagadish-dev18.github.io/Maintain-IQ/)

MaintainIQ is a responsive maintenance dashboard designed to organize factory equipment faults and track maintenance work orders.

### 🛡️ 3. LinkLens — URL Security Checker

🔗 **Live Demo:** [Open LinkLens](https://jagadish-dev18.github.io/Link-Lens/)

LinkLens is an educational URL inspection tool that analyzes URL structures and highlights characteristics that may require further investigation.

**Key Features**
- Analyze individual URLs and multiple URLs.
- Parse URL components, including protocol, hostname, port, and path.
- Check indicators such as IP-based hostnames, embedded credentials, unusual characters, punycode, long URLs, suspicious keywords, and unusual ports.
- Display individual findings with explanations.
- Calculate an explainable heuristic risk score based on configured rules.
- Keep recent scan history in browser storage.
- Export analysis reports as CSV or JSON.

**Tech Stack:** HTML5, CSS3, JavaScript, URL API, localStorage, CSV/JSON

**Concepts Practiced:** URL parsing, input validation, conditional logic, heuristic analysis, safe rendering, and report generation.

**Limitation:** The basic browser-only version performs URL-structure analysis. It does not independently verify every URL against live threat-intelligence databases. A low heuristic score does not prove that a URL is safe.

### 🔎 4. Log Sentinel — Failed Login Attempt Log Analyzer

🔗 **Live Demo:** [Open Log Sentinel](https://jagadish-dev18.github.io/Log-Sentinel/)

Log Sentinel is a security log-analysis tool that summarizes authentication events and identifies repeated failed-login attempts for further investigation.

**Key Features**
- Read supported authentication log formats.
- Identify successful and failed login events.
- Count failed login attempts by source IP address.
- Flag repeated failures above a configurable threshold.
- Display recognized events, flagged IP addresses, and unparsed lines.
- Generate an IP-wise analysis report.
- Export summary information as CSV.
- Includes a browser interface and a Python command-line analyzer.

**Tech Stack:** Python, HTML5, CSS3, JavaScript, File Handling, Dictionaries, CSV

**Concepts Practiced:** Log parsing, string processing, dictionaries, event grouping, threshold checks, error handling, and report generation.

**Limitation:** The analyzer processes selected log files. It does not monitor a live network or prove that a flagged IP address belongs to an attacker.
